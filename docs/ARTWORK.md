# Artwork provenance

The dot-eye appearance was supplied by the project owner as a visual reference. `assets/reference-eyes.png` is that reference; `scripts/eye-data.js` is its sampled point representation. The screenshot, preview image, and GIF show this same reference-derived artwork.

The original artist and original artwork license were not supplied. The code license does not claim ownership of or grant redistribution rights to this artwork. For reuse under a fully documented artwork license, replace the reference and regenerate the geometry with your own or appropriately licensed design.

The renderer and motion system are independent of the reference image at runtime. The Blender scripts from the initial investigation are not part of this repository.
