# Как представить проект в портфолио

**J · Living Eyes — интерактивные WebGL-обои для Wallpaper Engine.** Процедурная анимация точечного/ASCII-взгляда: инерция, повороты X/Y/Z, моргание, движения в покое и мягкое исчезновение радужек. Геометрия статична, анимация выполняется на GPU через uniform-параметры. Без runtime-зависимостей.

Что показать при разборе проекта:

- Почему здесь достаточно небольшого point cloud вместо тяжёлого 3D-движка.
- Как критически затухающая пружина даёт плавную реакцию без нестабильности при другом FPS.
- Как отделены радужки, веки и брови, и как работает маска исчезновения.
- Почему процедурная анимация не имеет стыка фиксированного видеолупа.
- Как учитываются FPS, пауза и свойства Wallpaper Engine.
- Что проверяют тесты и какие ограничения есть у псевдо-3D и Canvas2D.

Разработка выполнена с помощью ИИ и итераций по визуальной обратной связи. Представляй свою роль честно: постановка задачи, выбор вида, проверка поведения и доведение работающего проекта. Перед техническим собеседованием разберись в ключевых функциях и сделай самостоятельное улучшение, которое сможешь объяснить.

Это подходящий небольшой проект для направления frontend / creative coding / graphics. Для более общего портфолио его лучше дополнить приложением с данными, API и понятной прикладной задачей.
