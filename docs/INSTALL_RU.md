# Установка J · Living Eyes

**Браузер:** открой `preview.html` из корня проекта. Двигай мышью; H скрывает панель. `index.html` — обои без панели.

**Wallpaper Engine:**

1. Скопируй папку проекта в `steamapps/common/wallpaper_engine/projects/myprojects/j-living-eyes/` в той библиотеке Steam, где установлен Wallpaper Engine.
2. Открой редактор → существующий проект **J · Living Eyes** → сохрани и примени обои.
3. Настраивай цвет, трекинг, повороты, плотность, свечение и размер в правой панели Wallpaper Engine.

Можно перетащить `index.html` на «Создать обои». Если редактор пересоздал настройки, восстанови готовый `project.json` в импортированной папке. Включи ввод мыши для web-обоев, если трекинг отключён в приложении.

**Разработка:** Node.js 20+; `npm start` открывает сервер на http://127.0.0.1:8080/preview.html, `npm test` запускает проверки. Никаких npm-зависимостей устанавливать не нужно.

**Рисунок:** `scripts/eye-data.js`. **Рендер и исчезновение:** `scripts/renderer.js`. **Движения:** `scripts/motion.js`. **Курсор и цикл:** `scripts/main.js`. **Настройки:** `scripts/settings.js` и `project.json`.

Проверенная версия запущена в Wallpaper Engine; владелец проекта подтвердил работу. Полный обзор — в README.md.
